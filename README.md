🎬 KDTIG Movie Land – Cinema Booking System



A C console application for managing movie seat bookings, discounts, cancellations, and revenue reporting.  

This project was developed as a team exercise with responsibilities divided among five members.



\---



✨ Features

\- Display available movies and showtimes

\- Show seat map with pricing tiers (Regular, Premium, VIP)

\- Book seats with per‑ticket discounts:

&#x20; - Student (10%)

&#x20; - Senior (20%)

&#x20; - Group (≥4 tickets → extra 10% per ticket)

\- Prevent double booking of seats

\- Cancel bookings (only if seat is already booked)

\- Search bookings by customer name

\- Generate revenue reports (tickets sold + total revenue)

\- Clear and structured console UI



\---



🛠️ Compilation \& Execution



Using GCC (Command Line)

Compile and run the program:



bash

gcc core-setup.c -o booking

./booking
